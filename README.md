# claudeball

A Magic 8 Ball app built with React and Vite.

## Features

- Click the ball to shake it and reveal a random response
- 20 classic Magic 8 Ball answers across three categories
- Window color reflects the response type:
  - **Green** — positive responses
  - **Purple** — neutral / inconclusive responses
  - **Red** — negative responses
- Smooth shake animation and fade-in transition on each click

## Getting Started

```bash
npm install
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173).

## Tech Stack

- [React](https://react.dev/)
- [Vite](https://vite.dev/)
- Plain CSS (no UI library)
